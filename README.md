# Ascendia - Financial Platform

Financial platform for the Polish market with React frontend and Node.js backend.

## Project Status

- **Frontend**: Working
- **Backend**: Work in Progress

## Tech Stack

### Frontend
- React 18
- TypeScript
- React Router v6
- Vite
- Tailwind CSS
- i18next (PL/EN)
- Zustand (state management)
- React Hook Form + Zod

### Backend (Work in Progress)
- Node.js 18+
- Express.js
- PostgreSQL
- Prisma ORM
- TypeScript

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

The frontend will run on `http://localhost:3000`
